# SecureMailScope-
SecureMailScope checks how securely an email will travel before sending — MX, STARTTLS/TLS, MTA-STS, SPF/DKIM/DMARC, PQC readiness, AI-explained risk — then encrypts it in the browser with AES-256-GCM + RSA-OAEP-256. Private keys never leave the browser; recipients decrypt via the dashboard or Gmail extension. The mail server sees only ciphertext.
